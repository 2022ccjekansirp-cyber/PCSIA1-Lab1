# Hospital Database Management System

## Project Title
Hospital Database Management System for St. Elizabeth Hospital, General Santos City

## Target Organization
St. Elizabeth Hospital, Inc.

**Type:** Private Hospital  
**Location:** General Santos City

## Project Description

The Hospital Database Management System is a proposed information system
designed to centralize and manage hospital information efficiently.

The system is intended to help authorized hospital personnel manage patient
records, medical information, appointments, laboratory services, pharmacy
records, billing, and other hospital-related information through a centralized
database.

The proposed system aims to reduce duplicate records, minimize manual errors,
improve data retrieval, support communication between hospital departments,
and make report generation more efficient.

## Main Features

- Dashboard
- Patient Registration and Records
- Doctor and Medical Staff Management
- Appointment Management
- Emergency Department
- Inpatient and Admission Management
- Laboratory Management
- Radiology and Imaging
- Pharmacy Management
- Billing and Payments
- Medical Records
- Reports
- User and System Administration

## Hospital Departments and Services
